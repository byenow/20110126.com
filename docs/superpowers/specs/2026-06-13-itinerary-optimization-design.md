# 攻略页面优化设计 · 2026-06-13

在不改动整体业务风格（journal / planner / culture 三主题）的前提下，对东京五日攻略页做一轮功能与内容优化。所有决策经可视化伴侣 + 终端逐项确认。

## 范围总览

1. 出行互动（倒计时/进度、当天与当前项目高亮、checklist 勾选持久化）
2. 景点照片轮播（每地点 3–5 图）
3. 餐厅排期 + 餐厅卡（3 家，含 Tabelog 真实数据）
4. 6/20 行程重排（西向动线）
5. 待定区（新，承接移出行程的项目）
6. More to Explore 备选区（新，6 类 × 2）

## 1 · 出行互动（纯前端，按用户本地时间）

- **倒计时/进度卡**：放总览区。`now < 6/18` → 「距 6/18 出发 N 天」；`6/18–6/22` → 「Day N / 5」并高亮当天；`now > 6/22` → 「旅程已结束」。
- **当天 + 当前项目高亮**：行程进行中，对应日 section 高亮；该日时间线按当前时刻标「进行中 / 下一项」。
- **Checklist 勾选**：清单项变 checkbox，状态存 `localStorage('tokyo-checklist')`，已勾划掉。与现有主题持久化一致。
- 行程基准日期：`2026-06-18`～`2026-06-22`（Asia/Tokyo）。

## 2 · 景点照片轮播

- 每个景点卡由 2 图扩到 **3–5 图**，`photo-grid` 改为**轮播**（样式 A）：左右箭头 + 底部圆点 + 触摸滑动 + 键盘左右 + 每图独立说明/署名，**无自动播放**，遵循 `prefers-reduced-motion`。
- 非当前图 `loading="lazy"`；三主题适配；保留现有 figcaption 署名格式。
- 新增图片来源以 Wikimedia Commons 为主，统一压缩（宽 ~1000–1200px、合理质量）控制体积。
