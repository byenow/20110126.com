# 航班详情卡设计 · 2026-06-12

为「东京五日散策手册」补充资深飞友视角的航班信息，保持现有 journal / planner / culture 三套主题风格不变。

## 目标

在不改动整体业务风格的前提下，为去程 NH964（06.18）与返程 NH963（06.22）各补充一张「航班详情卡」，包含真实机型、航站楼、时长/距离、选座观景提示、呼号与巡航高度，并以编辑风航路图 + 真实机图背景呈现。

## 设计决策（经可视化伴侣逐项确认）

- **深度**：实用向 + 航路图。
- **航路图风格**：编辑风 SVG 弧线图（纯矢量、零外部依赖、随主题换色）。
- **放置**：嵌入对应行程日（06.18 / 06.22）内容区顶部。
- **字段**：机型 + 宽/窄体 + 典型注册号、航站楼、飞行时长 + 航线距离、选座/观景提示、呼号 + 巡航高度。
- **背景**：真实 ANA 767-300 实拍图做顶部横幅，向下渐隐入卡片（数据区保持纯净）。

## 实现

- `app.js`：在 06.18 / 06.22 两天加 `flightDetail` 结构化数据；新增 `renderFlightDetail()`；在 `renderDay` 内容区顶部按 `day.flightDetail` 注入。`trip.flights`（总览 Flights 卡片）保持不变。
- `styles.css`：新增 `.flight-card` 系列样式，颜色、渐隐遮罩（`color-mix` + `--surface`）、滤镜（`--image-filter`）、圆角全部沿用主题变量，<=640px 单列。
